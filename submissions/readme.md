### Submit Work Here
In order to submit your work you should:

1. Create a Fork of my repository.
2. In your fork create a branch for each assignment you are working on.
3. Save your work in the submissions folder in the assignments branch.
4. Merge your branch to your forked copy of main when you are done.
5. Create a pull request to submit your work back to my repository.

In order to avoid conflicts be sure to name your files using your name and the assignment name, i.e. `Project_1_Rocca.ipynb`
